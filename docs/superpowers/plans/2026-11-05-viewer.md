# 360° Viewer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An in-app viewer for equirectangular 360° photos (own and third-party), reachable from Detail, Home
(Photo Picker) and `ACTION_VIEW`; plus "Delete source images" in Detail.

**Architecture:** New Android library `:viewer` owning `ViewerActivity` (landscape allowed). Compose UI with a
`GLSurfaceView` (GLES 3.0) in `AndroidView`; a fullscreen-triangle fragment shader ray-casts into the equirect
texture. Pure-Kotlin `ViewMath` (rotation, ray → uv) and `GPano` (XMP parse) are JVM-tested; the shader mirrors
`ViewMath`. Gyro from `TYPE_GAME_ROTATION_VECTOR` directly (no dependency on `:capture`).

**Tech Stack:** Kotlin, Compose (BOM 2026.03.01), GLES 3.0, `ImageDecoder`, JUnit 4.

## Global Constraints
- minSdk 29, compileSdk/targetSdk 36, Java/JVM 17, arm64-v8a only.
- Permissions stay `CAMERA` + `VIBRATE`; no new ones.
- Equirect convention: lon = π − u·2π, lat = π/2 − v·π (u, v continuous in [0, 1]); centre column = yaw 0;
  world Z-up, yaw positive toward +Y (left); no mirroring.
- No new third-party dependency. Comments only for non-obvious things.

## Verified decisions
- XMP: framework `android.media.ExifInterface` has `TAG_XMP`, but JPEG APP1 XMP parsing in older platform
  versions is not guaranteed for minSdk 29; a ~40-line APP1 scanner is smaller to trust and JVM-testable.
  Extended XMP (`xmpNote:HasExtendedXMP`) is not read: GPano lives in the main packet.
- Texture size: decode with a long side ≤ 8192, then scale down at upload if `GL_MAX_TEXTURE_SIZE` is smaller
  (measured on the emulator and A16 in Task 6).
- Drag with gyro on changes yaw only (pitch comes from tilting the phone); with gyro off drag changes yaw and
  pitch (clamped ±90°).

### Task 1: `ViewMath` (JVM)
**Produces:**
- `object ViewMath`
  - `fun uvOf(d: FloatArray): FloatArray` – world dir (x, y, z) → (u, v)
  - `fun worldFromCamYawPitch(yawDeg: Float, pitchDeg: Float): FloatArray` – 3×3 row-major, camera frame
    OpenCV (x right, y down, z forward)
  - `fun worldFromCamGyro(gwFromDevice: FloatArray, displayRotationDeg: Int, yaw0Deg: Float, yawOffsetDeg: Float): FloatArray`
  - `fun headingDeg(worldFromCam: FloatArray): Float` – yaw of the camera forward
  - `fun ray(worldFromCam: FloatArray, ndcX: Float, ndcY: Float, tanHalfFovY: Float, aspect: Float): FloatArray`
- [ ] Tests: forward +X → u = 0.5, v = 0.5; +Y (left) → u = 0.25; +Z → v = 0; yaw 90 forward = +Y;
  pitch 90 forward = +Z; screen right of yaw-0 camera points to −Y (u > 0.5, no mirroring); gyro with
  device lying flat face up (camera points down) → forward −Z; display rotation 90 maps screen-right to device +y.
- [ ] Implement, run `./gradlew :viewer:testDebugUnitTest`, commit.

### Task 2: `GPano` (JVM)
**Produces:** `data class PanoCrop(left, top, width, height: Float)` as fractions of the full pano;
`object GPano { fun readXmp(input: InputStream): String?; fun crop(xmp: String?, imgW: Int, imgH: Int): PanoCrop? }`
(`null` = not a 360° photo; no XMP and 2:1 → full; attribute and element XMP forms).
- [ ] Tests: our stitcher's XMP string (copied from `stitcher/core/src/stitch.cpp`), a cropped one
  (element form), a JPEG byte stream with EXIF APP1 before XMP APP1, no XMP + 2:1, no XMP + 4:3.
- [ ] Implement, run tests, commit.

### Task 3: Renderer + `ViewerActivity`
- `PanoRenderer(bitmap, crop)`: GLES 3.0, fullscreen triangle, shader computes ray → lon/lat → uv like
  `ViewMath`, wrap-safe gradients (`dFdx`/`dFdy` with `x -= round(x)`, `textureGrad`), mipmaps, neutral
  colour outside the crop. Uniforms: `uRot` (mat3), `uTanHalfFov`, `uAspect`, `uCrop`.
- `ViewerActivity`: `intent(context, uri)`; decode via `ImageDecoder` (long side ≤ 8192), XMP via `GPano`;
  error text for non-panoramas; gestures on a transparent Compose overlay (`detectTransformGestures`);
  gyro toggle + close button; sensor and `GLSurfaceView` paused in `onPause`; `ACTION_VIEW image/jpeg` filter.
- [ ] Build, run on the emulator with our stitched pano and a cropped/non-pano JPEG, screenshot, commit.

### Task 4: Entry points

- Home: "Open 360 photo" → `PickVisualMedia(ImageOnly)` → `ViewerActivity` with `FLAG_GRANT_READ_URI_PERMISSION`.
- [ ] Build, try on the emulator, commit.

### Task 5: Delete source images
